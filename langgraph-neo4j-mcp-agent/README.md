# Neo4j MCP LangGraph ReAct Agents

LangGraph ReAct agents that connect to a Neo4j MCP server through an AWS Bedrock AgentCore Gateway and answer natural language questions using Claude.

## Layout

```
neo4j_mcp_agent/      Python package
  core.py             Shared agent logic (prompt, MCP client, LLM, demo)
  agent.py            Production agent: auto-refreshing OAuth2 token
  simple_agent.py     Simple agent: static token, no refresh
agent.sh              Entry point for the production agent
notebooks/            SageMaker Unified Studio notebooks
inference-profiles/   setup-inference-profile.sh + generated .env files
tests/                test_fastmcp.py connectivity check
docs/
  IAM.md              IAM permissions for the agents, script, and notebooks
  SAGEMAKER-MODELS.md Inference profile setup for SageMaker Unified Studio
```

## Setup

```bash
uv sync
cp ../neo4j-agentcore-mcp-server/.mcp-credentials.json .
```

`.mcp-credentials.json` is generated by the `neo4j-agentcore-mcp-server` deployment. Required fields: `gateway_url`, `token_url`, `client_id`, `client_secret`, `scope`, `region`.

## Agents

`core.py` holds the shared agent logic. The two entry points differ only in how they resolve credentials.

| Agent | Token handling | Use case |
|-------|----------------|----------|
| Production (`agent.py`) | Auto-refreshing OAuth2 client credentials grant | Long-running sessions, pipelines |
| Simple (`simple_agent.py`) | Static `access_token` from the file, expires in ~1 hour | Quick tests, learning the flow |

```bash
# Production agent (refreshes the token when it is expired or expiring soon)
./agent.sh                                     # Run demo queries
./agent.sh "How many aircraft are in the database?"

# Simple agent (static token)
uv run python -m neo4j_mcp_agent.simple_agent "What is the schema?"
```

The production agent checks `token_expires_at` on every run. When the token is within 5 minutes of expiry it requests a new one from the Cognito `token_url` using `client_id`/`client_secret`, writes it back to `.mcp-credentials.json`, and continues. AWS credentials for Bedrock come from the standard chain (`AWS_PROFILE`, environment variables, or instance role) and are separate from the gateway OAuth2 credentials.

## Configuration

| Setting | Where | Notes |
|---------|-------|-------|
| Model | `MODEL_ID` in `neo4j_mcp_agent/core.py` | `global.anthropic.claude-haiku-4-5-20251001-v1:0` |
| Region | `region` in `.mcp-credentials.json` | Falls back to `DEFAULT_REGION` in `core.py` (`us-east-1`) |
| Credentials path | `.mcp-credentials.json` at the project root | `agent.sh` runs from the project root |

## Notebooks (SageMaker Unified Studio)

The notebooks in `notebooks/` need a Bedrock application inference profile carrying the `AmazonBedrockManaged=true` tag. Create one with the script, then paste the ARN into the notebook configuration cell:

```bash
./inference-profiles/setup-inference-profile.sh --help
./inference-profiles/setup-inference-profile.sh haiku        # Create a haiku profile
./inference-profiles/setup-inference-profile.sh --test haiku  # Create and test
./inference-profiles/setup-inference-profile.sh --list        # Show profiles and tag status
```

| Notebook | Purpose |
|----------|---------|
| `notebooks/minimal_langgraph_agent.ipynb` | LangGraph + Bedrock smoke test |
| `notebooks/neo4j_simple_mcp_agent.ipynb` | Simple MCP agent over the gateway |
| `notebooks/neo4j_strands_mcp_agent.ipynb` | Strands MCP agent over the gateway |

See [docs/SAGEMAKER-MODELS.md](docs/SAGEMAKER-MODELS.md) for why the tag is required and how the script applies it, and [docs/IAM.md](docs/IAM.md) for the required permissions.

## Testing

```bash
uv sync --extra test
uv run python tests/test_fastmcp.py
```

`test_fastmcp.py` lists the gateway tools and calls `get-schema` and `read-cypher` directly with the FastMCP client (no LLM).

## Troubleshooting

| Symptom | Cause / fix |
|---------|-------------|
| `Token refresh failed: 401` | Wrong `client_id` / `client_secret` in `.mcp-credentials.json` |
| `NoCredentialsError` | AWS credentials not configured (`aws configure` or env vars) |
| `AccessDeniedException` on the model | Enable Claude model access in the Bedrock console |
| `httpx.ConnectError` | Wrong `gateway_url`, or the MCP server is not deployed |

## Gateway Tool Naming

Tools reached through the gateway are prefixed with the target name, for example `neo4j-mcp-server-target___get-schema`. `langchain-mcp-adapters` handles the prefix automatically.
